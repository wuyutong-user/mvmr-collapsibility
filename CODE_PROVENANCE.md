# Source and maintenance records

The package retains the archived simulation, application and plotting sources.
Original source hashes and prior validation records are preserved for comparison.

The 8 October 2026 maintenance reorganises the two reporting scripts, quotes
child script paths in the application launcher and standardises source comments.
Comments describe input formats and processing steps. The simulation model,
application estimates, thresholds, archived numerical results and figures are
unchanged. Validation records distinguish source checks from estimation reruns.
