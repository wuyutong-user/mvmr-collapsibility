# Source and maintenance records

The package retains the archived simulation and application sources, with
selected numerical main-figure plotting sources.
Original source hashes and prior validation records are preserved for comparison.

The 8 October 2026 maintenance reorganises the two reporting scripts, quotes
child script paths in the application launcher and standardises source comments.
Comments describe input formats and processing steps. The simulation model,
application estimates, thresholds, archived numerical results and figures are
unchanged. Validation records distinguish source checks from estimation reruns.

The 9 October 2026 archive synchronisation aligns the downloadable ZIP with
the repository's slim Figure 2, 3 and 5 plotting directory. The Figure 3 input
combines the eight required columns of the 24 archived binary primary outputs;
response values match the archived figure source. PowerPoint files, obsolete
plotting sources, supplementary plotting scripts and preview exporters are
outside the new source bundle. No simulation or application estimate is rerun.
The source bundle inside the ZIP excludes repository delivery files to avoid
recursive checksum dependencies.
