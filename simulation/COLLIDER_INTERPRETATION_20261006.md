# Collider interpretation — 6 October 2026

The Collider role alone does not determine an adjustment decision in summary-data MVMR. In the canonical continuous DGP, y = beta_X x and, for a full-rank [x,z] design with positive-definite weights, beta_unadj = beta_adj = beta_X and alpha_Z = 0. Candidate-trait inclusion therefore preserves the additive target in this canonical model. An application Collider label remains Unclassified unless retained-instrument evidence resolves the consequence of inclusion.

This interpretation supersedes the historical Collider `nominal_adjustment_class` metadata in `01_role_registry.R`; that frozen file and all numerical model inputs/results remain unchanged. This is an interpretation/reporting revision, not a new simulation run. Independent-cause rules and application labels are unchanged.
